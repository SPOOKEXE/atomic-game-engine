# Standards and conventions

What a change is held to: how the code is written, how it is commented, what it
is reviewed against, and what has been deliberately put off.

`QUIC` is the odd one out and is here rather than under Repository on purpose:
it is not a standard, it is the survey a deferred entry points at, and it sits
beside `DEFERRED` because that is the only place anybody would think to look for
it.
