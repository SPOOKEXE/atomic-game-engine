# Palette Extract native CPU profile

The implementation follows Pixel Composer b69eca232217360cf1502ef0223523d818606652 `scripts/node_palette_extract/node_palette_extract.gml`, SHA-256 `f47e7a889528b6c4813fb5b471df505d7f03b0d5377d9bd05df2c5e993c6fb3a`. The authored selector exposes K-mean, Frequency and All Colors. Its defaults are K-mean, HSV and five colors. Radius belongs to an existing MeanShift helper reachable only through internal algorithm value 3; the constructor choices and hotkey cycling expose only 0..2. This profile does not expose MeanShift.

K-mean reduces each dimension independently to at most 32 texels. Every requested center, clamped to a minimum of one, requires three caller-recorded `random(1)` observations. The seed is retained as a resolved control; native code never generates GameMaker draws. Eight assignment/centroid iterations use Euclidean distance in normalized RGB or HSV, first-index distance ties and zero-valued empty clusters. Each final center selects its nearest original sampled color. Publication converts it through source RGB or HSV color construction, forces alpha 255 and removes duplicates in center encounter order. Fully transparent input reaches the source helper's invalid empty-color dereference; native execution refuses explicitly and preserves the prior result.

The source palette sorter returns boolean 0/1 rather than a three-way comparison. Official HTML5 `array_sort` forwards that comparator into JavaScript `.sort`; the included actual-runtime probe verifies preserved input order on Node 24.15.0/V8. Native K-mean retains that verified center-order profile. Licensed desktop sort parity is unverified.

Frequency reduces each dimension independently to at most 128 texels, counts complete packed RGBA colors and selects the largest frequencies. Official HTML5 `ds_map` iterates insertion order; its priority queue appends equal-priority entries and `delete_max` takes the last entry. Native frequency ties therefore use reverse first-encounter order. All Colors uses the original source dimensions, preserves full RGBA identity and emits distinct colors in first-encounter order, matching official HTML5 `array_unique_ext`. Native byte alpha 0 samples are skipped.

The source's Frequency alpha expression (`b & (FF<<24) >>24`) and All Colors test (`c & bm ==0`) lack complete grouping. Official GML documentation warns that ungrouped expressions can evaluate differently across target compilers. The native profile explicitly tests the RGBA alpha byte; target-specific precedence and licensed desktop outputs require a source receipt, not an inferred parity claim.

Sampling uses unfiltered texel centers. A mask is drawn at(0,0) at its own dimensions after copying the source into a source-sized RGBA8 temporary, using source `BLEND_MULTIPLY` (`bm_dest_colour`, `bm_zero`). Mask RGB and alpha multiply all destination channels. Uncovered destination pixels receive no mask fragments and retain the copied source; larger masks clip to the source target. Transparent covered mask fragments erase destination alpha. The source ignores Mask Alpha Only in this direct blend path, so native execution also multiplies RGB when that attribute is true.

Depth handling follows the source helper signatures: `surface_create_valid(...,format=surface_rgba8unorm)` and `surface_verify(...,format=surface_rgba8unorm)`. Frequency and All Colors omit the format argument, so their temporary/readback is RGBA8 even for typed/HDR input. Mask composition also copies into a default RGBA8 target before multiplying, including source clipping/quantization before the mask draw. K-mean supplies `attrDepth()` but still allocates four bytes per pixel and reads `buffer_u32`; native K-mean admits only selected RGBA8 depth until other source byte-layout behavior is proven. GPU quantization/filter state, channel swizzle, readback orientation and desktop renderer parity are external acceptance gates.

Main-surface arrays use the existing source processor row scheduler. Mask and source controls reject arrays as specified by `array_foreach(inputs,...rejectArray(),1)`. Scalar preparation can capture K-mean inputs; the generic preparation API still refuses image arrays without a per-row source recording contract. Caller-provided row records retain the existing node/row/time identity contract.

Bounds are checked before owned growth:4096 published colors; at most 2^26 sampled pixels across a processor batch; at most 2^24 clustering/representative/uniqueness comparisons across a batch; fixed-size center/point storage; preadmitted map nodes and frequency rows. Failure preserves the previous published value and replay. There is no ambient RNG, source filesystem access or renderer dependency.

Primary supporting sources are the pinned project's `surface_functions.gml`, `shader_functions.gml`, `_draw_defines.gml`, and `color_function.gml`; official GameMaker HTML5 commit 60e51be51ce7f3d52025ef18106cf172b8e22a00 `Function_Variable.js`, `Function_Graphics.js`, `ds_map.js`, `ds_priority.js`, `yyOList.js` and `yyWebGL.js`.
