# Flow Noise CPU contract

`pc.flow_noise` executes the pinned Pixel Composer `Node_Flow_Noise` constructor and `sh_noise_flow` formulas from revision `b69eca232217360cf1502ef0223523d818606652`. Its output is `surface_out`. This is a bounded native double-precision CPU profile, with pixel-center UV sampling and the existing nearest-neighbor source surface sampler. Device float arithmetic, trigonometry, filtering and rendered pixel parity require a real renderer oracle. No device parity is claimed.

The raw canvas sets the Y aspect ratio and Position divisor. Allocation rounds dimensions half to even and clamps allocation to at least one pixel; a zero raw canvas divisor is refused. Position defaults to Reference units and resolves against the first prepared raw canvas before processor selection. Linked numeric vectors receive those units. Linked scalar surfaces project their dimensions before units; whole surface arrays used as Vec2 or SliRange inputs take the source nonsurface fallback `{1,1}`. Dimension surface arrays project their constituent dimensions before processor selection, including the source equal-dimension collapse. Float Progress and Slider UV Mix surface getters produce dimension components that become scalar processor rows. Rotation surface handles and unsupported path/casting branches remain explicit typed-getter diagnostics.

Progress defaults to zero, Detail to `{1,8}`, Position to zero, Rotation to zero degrees and Scale to `{2,2}`. Detail advances by one from the authored lower endpoint, including fractional and negative values. Each step updates X using sine, then updates Y using the new X and cosine. An inverted range executes no steps. Zero Scale is defined and still receives these deformation updates. Rotation converts degrees once inside the formula. Level In and Out default to `{0,1}`; reversal and extrapolation remain unclamped until typed storage. SliRange numeric scalar links duplicate into both endpoints; short numeric arrays pad zeros and excess components are clipped, as in the pinned Array getter.

A visited zero Detail divisor, stalled native increment, zero Level In span or nonfinite computed output is refused rather than assigned invented pixels. UI display limits do not clamp Detail. The shader loop uses float on devices; this profile uses double and does not claim matching device increment behavior for large or cancellation-sensitive inputs.

UV Map red supplies X, green supplies inverted Y, and UV Mix interpolates coordinates. Map alpha is consumed even at zero Mix. The inherited mask pass uses the source RGBA8 intermediate and mean RGB times alpha before final typed storage; `mask_alpha_only` is inert for this generator branch. Inherited and all seven explicit surface depths use the existing typed surface pipeline. There is no Seed, Active or mapped numerical control in this source constructor.

Before the first output allocation, original Detail leaves and original canvas rows are inspected. Work is conservatively quoted at 512 weighted operations/read units per pixel plus 32 per admitted Detail step, with an extra step in the loop bound to cover native increment rounding. The existing generator admission limits the whole batch to 64 million units. It quotes 16 bytes per pixel plus image/output/port row metadata for every processor row, covering later typed formats before publication. Original input storage remains charged. Loop, Hold, Expand and Expand Inverse preserve original row selection, and output replacement remains atomic on failure.

The accompanying authored graph fixtures cover formula-derived literal pixels, transforms, signed/fractional/inverted loops, source units and surface getters, UV and mask alpha, seven typed depths, original-row schedules, inherited instances, keyframes, native save/load and work/byte refusals. The golden script independently evaluates the formula with Python double arithmetic; it is not a renderer capture.
