# Cristal Noise CPU contract

`pc.noise_cristal` follows the pinned `Node_Noise_Cristal` constructor and `sh_noise_cristal` equations at revision `b69eca232217360cf1502ef0223523d818606652`. The shader attributes its original Cristal noise to doolhong and links `https://www.shadertoy.com/view/XX33zs`. The upstream Pixel Composer license notice remains distributed with this module. The native route is a bounded double-precision CPU profile with pixel-center UV coordinates and nearest surface sampling. It does not claim device float, trigonometric, filtering or captured pixel parity.

The authored Seed is required because the source constructor initializes a random seed. Seed reduction is the literal floor modulo 100000 divided by 10. Iteration defaults to 15 and uses the source half-even Int getter before processor selection. Phase defaults to zero degrees. Position defaults to zero in Reference units, and Scale defaults to `{1,1}`. Raw canvas dimensions retain the Y aspect and Position divisors; allocation separately rounds half to even and clamps allocation to at least one pixel. Zero raw divisors are diagnosed.

The Oilnoise recurrence initializes `aPos` from absolute fractional coordinates. Every iteration rotates Position by Phase, computes the two cosines with increasing frequency and `aPos`, adds the sine contribution using the shader's literal `TAU = 6.283184`, then updates and rotates `aPos` by five degrees and scales it by 1.232. The overwritten earlier assignment to q has no observable effect. The sum is raised to 4.504. RGB is divided by the last q fractional edge and the powered sum, then clamped to `{0,1}`. Color RGB times Gamma enters this normalization; Color alpha is inert. Gamma defaults to one, and its UI range does not clamp authored values. Zero and negative Gamma produce black when the normalization is defined. Level In and Out default to `{0,1}` and apply after the RGB clamp, including reversed and extrapolated levels.

Nonpositive Iteration leaves a zero output divisor and is diagnosed. Unrepresentable shader-int counts, zero Level In span, nonfinite transformed coordinates or recurrence and zero/nonfinite output normalization are also diagnosed. A GPU may expose different float overflow, trigonometric or division behavior. This profile neither fabricates those device observations nor promises equivalent failure thresholds.

The scalar Color route accepts typed colors and the existing integral packed-color profile with red, green and blue in the low three bytes. Fractional or out-of-profile numeric color conversion remains an explicit refusal. It uses the same engine interpretation helper as other source color routes. Rotation and Seed surface-handle casting are not replaced by an invented dimension getter.

Reference Position is resolved against the first prepared raw canvas before processor row selection. Numeric Vec2 inputs receive units; scalar surface Vec2 getters project dimensions before units. A whole surface array passed to Vec2 or SliRange takes the source nonsurface `{1,1}` fallback. Short numeric tuples pad zeros and excess components clip to two. Linked Dimension surface arrays project their constituent dimensions before processor selection, including equal-size collapse. Int Iteration and Slider Gamma/UV Mix surface getters produce scalar dimension components before row selection.

UV Map red supplies X and inverted green supplies Y, with UV Mix interpolation. Map alpha remains active at zero Mix. The inherited source mask pass uses an RGBA8 intermediate, mean RGB times alpha and final typed storage. Mask Alpha Only is source-inert. All seven explicit depths and inherited project depth use the existing bounded typed pipeline. There is no Active or mapped numerical control in this constructor.

Before any output allocation, original Iteration leaves and all original canvas/unit/image rows are admitted. The conservative work quote is 512 weighted scalar reads/arithmetic/math-call units per pixel plus 128 per maximum original positive iteration, bounded to 64 million units across the entire processor batch. The existing complex-generator admission quotes 16 bytes per pixel plus row/output/port metadata for every row, so later formats cannot evade the first-row byte check. Inputs remain charged and output replacement is atomic. Expand Inverse retains the pinned full-slot suffix reversal, including repeated pairs for singleton source constructor slots.

## Scratch route localization

The pinned Scratch shader consumes `length(fwidth(p)) * softness`, then calls `smoothstep(thick + f, thick - f, x)` inside each octave. With the default positive Softness and a nonzero derivative width, its edges are reversed; at zero derivative width they coincide. These cases are undefined by [GLSL section 8.3](https://registry.khronos.org/OpenGL/specs/gl/GLSLangSpec.4.60.html). Negative Softness can produce increasing edges, but still consumes renderer fragment derivatives. No portable CPU finite-difference substitute, default reverse-edge step, new public derivative carrier or partial placeholder executor is added. A real device implementation and captured derivative/raster observations remain necessary to establish a defined native profile for that source family.
