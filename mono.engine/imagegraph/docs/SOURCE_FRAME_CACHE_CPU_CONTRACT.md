# Source frame caches on the CPU

The pinned Pixel Composer source commit is `b69eca232217360cf1502ef0223523d818606652`. `native-frame-cache-policy.json` records the audited files and hashes. This contract covers `pc.cache` and `pc.cache_array` using caller-owned `DataReplayState`; it does not reuse Cache Results cycle storage.

Cache recovers a stored frame before entering its update. On a played miss it snapshots the whole connected surface value, including nested arrays. On a paused miss the inherited automatic wrapper still stores its retained output. A fresh paused Cache therefore stores source `noone=-4`, and playing that same frame later treats that sentinel as a miss. Animated changes scheduling only when the source update runs on a miss.

Cache Array captures only played, valid in-range observations. Start is one-based except negative Start maps to zero; negative Stop resolves to TOTAL_FRAMES. Stop is exclusive. Stop less than Start and nonpositive Step leave the prior output untouched. Equality also leaves output untouched because no observation is in range. Every in-range observation captures, including frames omitted by Step. Published missing positions retain numeric `-1`, so downstream Sequence can select valid frames while diagnosing an absent selected frame. Paused, invalid and out-of-range observations retain the exact last emitted shape.

Playback is explicit in `EvaluationRequest.SourceCachePlayback`. `ObservedFrame` preserves actual caller observation order. It never invents intermediate played calls: a mixed stateful noncontiguous seek requires a recorded scheduler or returns a capability diagnostic. `NativePlayedPrefix` is a deterministic CPU sampling profile with Playing=true for each replayed frame, chosen explicitly by client and native export callers. It is not the source Studio pause/play scheduler. Studio binds the frozen preview playback observation and includes Playing in its cache identity.

Same-clock Playing refresh restores the immutable pre-frame journals for the other state families. Observed caches retain their current captured frames and latest output, matching the source paused return. Native played-prefix refresh uses the pre-observation latest output. Refresh touching an unsafe Lua session is refused before side effects. No cache observation or journal is published on failure.

Frame captures and latest output are distinct owned records. Tagged rows retain durable node ID/type and processor row, preserve cache history across authored control revisions and replay restart, and retire when a node is removed or changes type. Whole owner Clear discards them. Seeks retain known frame snapshots but do not borrow a future latest output as a fabricated earlier result. Pixel Builder recipes own the observation by value and restore it synchronously during rasterization.

Inputs, normalization, retained state, candidate history and published surface generations are preadmitted together. The native profile accepts integer nonnegative clocks, at most4094 timeline frames and4096 published positions, bounded nested arrays and finite CPU surface samples. Supported image formats are copied without an RGBA8 conversion. Source cacheArrayCheck allocates TOTAL_FRAMES+1 positions, so frame N is a valid capture for N timeline frames and frame N+1 is outside storage. The native tagged history limit is independently4096 records, including two metadata records. A fully populated N=4094 cache therefore refuses its final extra-slot capture atomically; sparse observations at that slot remain supported. Membership/merge work and frame storage are bounded before allocation or mutation.

PXC import/writeback preserves explicit Serialize, Cache Group and serialized cache-string metadata. Missing properties remain absent. Malformed metadata stays opaque rather than being coerced. Selected Enable/Disable branches apply through the owned journal and pending dispatch paths described below. Unknown authoritative project observations refuse selected nonempty actions. Cache hits, paused returns and gated actions can retain their outputs without changing activity. Saved frames load through exact-source owned decode receipts or cooked native constructor packets; unbound compressed GPU data is refused. Serialize=false bypasses those source serialization/group behaviors.

Catalogue outputs retain exact source constructor expressions and bounded literal initial values separately from declared socket types. A surface output can start as `noone` or an empty source array. Reviewed zero Matrix constructors, named colour constants, CURVE_DEF_01 and one-key gradientObject constructors carry owned native values. Matrix Identity starts with the source zero matrix until its update runs. Nested colour arrays keep their source shape. Folding does not execute getters, drivers or node updates. Cold Join and Combine own empty source operations with zero line counts; Shift and Weight Adjust own their missing-path constructor controls. Path 3D retains present empty spatial ownership. Join preserves a supplied point buffer; a missing Combine line returns a fresh planar origin point without changing that buffer. Missing Shift/Weight Adjust paths reset x/y while preserving point class, z and weight. Their bounds retain the source sentinel or unit box as appropriate. Other runtime object expressions remain unresolved. Group initialization parses these values under the shared byte budget before frozen getter restoration.

`CacheGroupReplayState` owns named producer values, surfaces, nested arrays, socket domains and output refusals. Its bounded policy API preserves overlapping loaded lists and last-refreshed owner pointers. Interactive transfers remove the old owner first and wake that member. Enable and owner destruction respect Serialize/loading/appending gates and return an explicit force-clear request for the host. Disable additionally requires Playing and the rounded authoritative project endpoint. Serialize changes alone preserve activity. The policy distinguishes ordinary activity gates from explicit renderList bypass. Replacement snapshots preserve activity and ownership, reject node-type changes, and publish atomically under live-byte and comparison-work bounds.

`DataReplayState` embeds the group journal. Its retained-byte count and validation include producer snapshots, including Pixel Builder recipe copies. Frame-row Clear preserves the source group journal; frame-row overlays preserve the target observation's group journal. Stateful evaluation copies and reconciles snapshots by exact node ID/type before kernels run. Retiring an enabled owner requires authoritative loading/appending observations, applies source destruction gates and removes orphan membership pointers. Retained paths shed evaluation-local memo identities without changing the caller's snapshot. Direct and stateful output evaluation restore frozen named values, surfaces, nested arrays, exact socket domains and port-specific refusals before reading inputs or dispatching kernels. Frozen producers cut upstream dependencies while independent selected roots still run. Native image collectors recover indexed nested image-array shape. Restore copies obey the current request image dimension and live-byte bounds. Input inspection of a frozen node requires an explicit source render-list profile and remains refused. Active tracked producers replace only their published getter snapshots before intermediate results are freed. Uncomputed constructor ports, owner pointers and activity remain intact. Captured sequential paths receive late downstream memo updates before journal publication, then shed evaluation-local identities; simulation aliases are resolved against the final candidate state. Native root surfaces retain the 64 MiB output bound, while nested typed arrays keep the 4 MiB value bound. Clone residency and name-comparison work are admitted across the evaluation. Load-time authored initialization resolves bounded string membership lists in document owner order, preserves loaded overlaps and repeated IDs, skips missing IDs, and keeps existing producer getters/activity. Refusal preserves both journals. `CapturedFeedbackHost::RefreshLoadedSourceCacheGroups` stages current and preframe groups without clearing frame rows or latest pixels. Noncontiguous preparation copies the retained group journal before frame-row overlay, preserving callback order through cold and revised native played-prefix preparation. Studio fresh-document notifications stage a new initialized host and replace the old host only after admission. Full Studio append controls, runtime loading steps and broader seek policy remain separate work. Stateful Cache/Cache Array actions follow the dispatch rules below.

Selected Clear uses the shared captured host action for Cache Results, Cache and Cache Array. Cache forces Clear even when serialization is disabled or the project is loading/appending. Cache Array clears only when serialization is enabled and the project is neither loading nor appending. Selected input captures clear even when Cache Array keeps its frame slots. Captured slots clear atomically in current and preframe journals, while owned last output, project clock, authored metadata and unrelated previews remain unchanged. An exact-source, node-wide constructor suppression flag prevents cleared native or external receipts from loading again in previously unseen processor rows. The next admitted observation rebuilds live slots. The source button action wakes all retained owner-list members when Serialize is enabled and the project is neither loading nor appending, including loaded overlaps whose member pointer names another owner. It preserves getters, domains, refusals and membership while invalidating member and consumer previews in the host. Nonempty enabled groups require authoritative project observations; partial journals need authored initialization before enabling. Cold empty preframe journals have no frozen members to wake. Ordinary selected group members initialize the host journal even without another stateful node in their selected cone. Freed GPU handles, asynchronous source loading and exact device surface aliases remain source workflow gates. CPU ownership does not claim those behaviors. The official [surface_copy manual](https://manual.gamemaker.io/lts/en/GameMaker_Language/GML_Reference/Drawing/Surfaces/surface_copy.htm) describes copying without changing the source and warns that surfaces may cease to exist; the CPU snapshot profile cannot substitute for licensed device lifecycle evidence.
