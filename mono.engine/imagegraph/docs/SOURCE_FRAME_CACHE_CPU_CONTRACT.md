# Source frame caches on the CPU

The pinned Pixel Composer source commit is `b69eca232217360cf1502ef0223523d818606652`. `native-frame-cache-policy.json` records the audited files and hashes. This contract covers `pc.cache` and `pc.cache_array` using caller-owned `DataReplayState`; it does not reuse Cache Results cycle storage.

Cache recovers a stored frame before entering its update. On a played miss it snapshots the whole connected surface value, including nested arrays. On a paused miss the inherited automatic wrapper still stores its retained output. A fresh paused Cache therefore stores source `noone=-4`, and playing that same frame later recovers that sentinel. Animated changes scheduling only when the source update runs on a miss.

Cache Array captures only played, valid in-range observations. Start is one-based except negative Start maps to zero; negative Stop resolves to TOTAL_FRAMES. Stop is exclusive. Stop less than Start and nonpositive Step leave the prior output untouched. Equality also leaves output untouched because no observation is in range. Every in-range observation captures, including frames omitted by Step. Published missing positions retain numeric `-1`, so downstream Sequence can select valid frames while diagnosing an absent selected frame. Paused, invalid and out-of-range observations retain the exact last emitted shape.

Playback is explicit in `EvaluationRequest.SourceCachePlayback`. `ObservedFrame` preserves actual caller observation order. It never invents intermediate played calls: a mixed stateful noncontiguous seek requires a recorded scheduler or returns a capability diagnostic. `NativePlayedPrefix` is a deterministic CPU sampling profile with Playing=true for each replayed frame, chosen explicitly by client and native export callers. It is not the source Studio pause/play scheduler. Studio binds the frozen preview playback observation and includes Playing in its cache identity.

Same-clock Playing refresh restores the immutable pre-frame journals for the other state families. Observed caches retain their current captured frames and latest output, matching the source paused return. Native played-prefix refresh uses the pre-observation latest output. Refresh touching an unsafe Lua session is refused before side effects. No cache observation or journal is published on failure.

Frame captures and latest output are distinct owned records. Tagged rows retain durable node ID/type and processor row, preserve cache history across authored control revisions and replay restart, and retire when a node is removed or changes type. Whole owner Clear discards them. Seeks retain known frame snapshots but do not borrow a future latest output as a fabricated earlier result. Pixel Builder recipes own the observation by value and restore it synchronously during rasterization.

Inputs, normalization, retained state, candidate history and published surface generations are preadmitted together. The native profile accepts integer nonnegative clocks, at most4094 timeline frames and4096 published positions, bounded nested arrays and finite CPU surface samples. Supported image formats are copied without an RGBA8 conversion. Source cacheArrayCheck allocates TOTAL_FRAMES+1 positions, so frame N is a valid capture for N timeline frames and frame N+1 is outside storage. The native tagged history limit is independently4096 records, including two metadata records. A fully populated N=4094 cache therefore refuses its final extra-slot capture atomically; sparse observations at that slot remain supported. Membership/merge work and frame storage are bounded before allocation or mutation.

PXC import/writeback preserves explicit Serialize, Cache Group and serialized cache-string metadata. Missing properties remain absent. Malformed metadata stays opaque rather than being coerced. Enabled nonempty cache groups and serialized loading return explicit diagnostics because native synchronous evaluation cannot reproduce the source scheduler or decode its compressed GPU caches. Serialize=false bypasses those source serialization/group behaviors.

Selected Cache/Clear Cache buttons, freed GPU handles, asynchronous source loading and exact device surface aliases remain source workflow gates. CPU ownership does not claim those behaviors. The official [surface_copy manual](https://manual.gamemaker.io/lts/en/GameMaker_Language/GML_Reference/Drawing/Surfaces/surface_copy.htm) describes copying without changing the source and warns that surfaces may cease to exist; the CPU snapshot profile cannot substitute for licensed device lifecycle evidence.
