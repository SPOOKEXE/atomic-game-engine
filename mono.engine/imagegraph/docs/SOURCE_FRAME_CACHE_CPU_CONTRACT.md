# Source frame caches on the CPU

The pinned Pixel Composer source commit is `b69eca232217360cf1502ef0223523d818606652`. `native-frame-cache-policy.json` records the audited files and hashes. This contract covers `pc.cache` and `pc.cache_array` using caller-owned `DataReplayState`; it does not reuse Cache Results cycle storage.

Cache recovers a stored frame before entering its update. On a played miss it snapshots the whole connected surface value, including nested arrays. On a paused miss the inherited automatic wrapper still stores its retained output. A fresh paused Cache therefore stores source `noone=-4`, and playing that same frame later treats that sentinel as a miss. Animated changes scheduling only when the source update runs on a miss.

Cache Array captures only played, valid in-range observations. Start is one-based except negative Start maps to zero; negative Stop resolves to TOTAL_FRAMES. Stop is exclusive. Stop less than Start and nonpositive Step leave the prior output untouched. Equality also leaves output untouched because no observation is in range. Every in-range observation captures, including frames omitted by Step. Published missing positions retain numeric `-1`, so downstream Sequence can select valid frames while diagnosing an absent selected frame. Paused, invalid and out-of-range observations retain the exact last emitted shape.

Playback is explicit in `EvaluationRequest.SourceCachePlayback`. `ObservedFrame` preserves actual caller observation order. It never invents intermediate played calls: a mixed stateful noncontiguous seek requires a recorded scheduler or returns a capability diagnostic. `NativePlayedPrefix` is a deterministic CPU sampling profile with Playing=true for each replayed frame, chosen explicitly by client and native export callers. It is not the source Studio pause/play scheduler. Studio binds the frozen preview playback observation and includes Playing in its cache identity.

Same-clock Playing refresh restores the immutable pre-frame journals for the other state families. Observed caches retain their current captured frames and latest output, matching the source paused return. Native played-prefix refresh uses the pre-observation latest output. Refresh touching an unsafe Lua session is refused before side effects. No cache observation or journal is published on failure.

Frame captures and latest output are distinct owned records. Tagged rows retain durable node ID/type and processor row, preserve cache history across authored control revisions and replay restart, and retire when a node is removed or changes type. Whole owner Clear discards them. Seeks retain known frame snapshots but do not borrow a future latest output as a fabricated earlier result. Pixel Builder recipes own the observation by value and restore it synchronously during rasterization.

Inputs, normalization, retained state, candidate history and published surface generations are preadmitted together. The native profile accepts integer nonnegative clocks, at most4094 timeline frames and4096 published positions, bounded nested arrays and finite CPU surface samples. Supported image formats are copied without an RGBA8 conversion. Source cacheArrayCheck allocates TOTAL_FRAMES+1 positions, so frame N is a valid capture for N timeline frames and frame N+1 is outside storage. The native tagged history limit is independently4096 records, including two metadata records. A fully populated N=4094 cache therefore refuses its final extra-slot capture atomically; sparse observations at that slot remain supported. Membership/merge work and frame storage are bounded before allocation or mutation.

PXC import/writeback preserves explicit Serialize, Cache Group and serialized cache-string metadata. Missing properties remain absent. Malformed metadata stays opaque rather than being coerced. Selected Enable/Disable branches that would change a nonempty cache group return an explicit diagnostic because native synchronous evaluation cannot yet reproduce the source scheduler. Cache hits, paused returns and gated actions can retain their outputs without changing activity. Saved frames load through exact-source owned decode receipts or cooked native constructor packets; unbound compressed GPU data is refused. Serialize=false bypasses those source serialization/group behaviors.

Catalogue outputs retain exact source constructor expressions and bounded literal initial values separately from declared socket types. A surface output can start as `noone` or an empty source array. Runtime object expressions remain unresolved. This metadata supports future cold disabled-member restoration; it does not enable cache-group scheduling.

`CacheGroupReplayState` owns named producer values, surfaces, nested arrays, socket domains and output refusals. Its bounded policy API preserves overlapping loaded lists and last-refreshed owner pointers. Interactive transfers remove the old owner first and wake that member. Enable and owner destruction respect Serialize/loading/appending gates and return an explicit force-clear request for the host. Disable additionally requires Playing and the rounded authoritative project endpoint. Serialize changes alone preserve activity. The policy distinguishes ordinary activity gates from explicit renderList bypass. Replacement snapshots preserve activity and ownership, reject node-type changes, and publish atomically under live-byte and comparison-work bounds.

`DataReplayState` embeds the group journal. Its retained-byte count and validation include producer snapshots, including Pixel Builder recipe copies. Frame-row Clear preserves the source group journal; frame-row overlays preserve the target observation's group journal. Stateful evaluation copies and reconciles snapshots by exact node ID/type before kernels run. Retiring an enabled owner requires authoritative loading/appending observations, applies source destruction gates and removes orphan membership pointers. Retained paths shed evaluation-local memo identities without changing the caller's snapshot. Direct and stateful output evaluation restore frozen named values, surfaces, nested arrays, exact socket domains and port-specific refusals before reading inputs or dispatching kernels. Frozen producers cut upstream dependencies while independent selected roots still run. Native image collectors recover indexed nested image-array shape. Restore copies obey the current request image dimension and live-byte bounds. Input inspection of a frozen node requires an explicit source render-list profile and remains refused. Active tracked producers replace only their published getter snapshots before intermediate results are freed. Uncomputed constructor ports, owner pointers and activity remain intact. Captured sequential paths receive late downstream memo updates before journal publication, then shed evaluation-local identities; simulation aliases are resolved against the final candidate state. Native root surfaces retain the 64 MiB output bound, while nested typed arrays keep the 4 MiB value bound. Clone residency and name-comparison work are admitted across the evaluation. Load-time authored initialization resolves bounded string membership lists in document owner order, preserves loaded overlaps and repeated IDs, skips missing IDs, and keeps existing producer getters/activity. New tracked producers receive exact catalogue literal constructor values; unresolved runtime and dynamic constructors retain explicit port refusals. Fresh stateful observations initialize nonempty authored groups once before capture. Later ticks preserve interactive membership and activity; explicit load refresh is separate from interactive transfer. Cache/Cache Array transitions, runtime resource constructor initialization, revision/seek activity policy and edit-triggered host actions still require integration; enabled nonempty authored groups remain refused.

Selected Clear uses the shared captured host action for Cache Results, Cache and Cache Array. Cache forces Clear even when serialization is disabled or the project is loading/appending. Cache Array clears only when serialization is enabled and the project is neither loading nor appending. Selected input captures clear even when Cache Array keeps its frame slots. Captured slots clear atomically in current and preframe journals, while owned last output, project clock, authored metadata and unrelated previews remain unchanged. An exact-source, node-wide constructor suppression flag prevents cleared native or external receipts from loading again in previously unseen processor rows. The next admitted observation rebuilds live slots. The source button action wakes all retained owner-list members when Serialize is enabled and the project is neither loading nor appending, including loaded overlaps whose member pointer names another owner. It preserves getters, domains, refusals and membership while invalidating member and consumer previews in the host. Nonempty enabled groups require authoritative project observations; partial journals need authored initialization before enabling. Cold empty preframe journals have no frozen members to wake. Ordinary selected group members initialize the host journal even without another stateful node in their selected cone. Automatic Cache update-loop transitions, freed GPU handles, asynchronous source loading and exact device surface aliases remain source workflow gates. CPU ownership does not claim those behaviors. The official [surface_copy manual](https://manual.gamemaker.io/lts/en/GameMaker_Language/GML_Reference/Drawing/Surfaces/surface_copy.htm) describes copying without changing the source and warns that surfaces may cease to exist; the CPU snapshot profile cannot substitute for licensed device lifecycle evidence.

Clear admission charges the largest sequential validation table, including group output sorting, beside retained and replacement journals. A full 4096-row ledger can clear existing matching rows; only an absent cache requires room for a constructor row. One-byte-short live budgets preserve the caller's prior journal.

Cache Array returns before Surface, range and Step getters when paused, unlinked or fed by a frozen producer. Its latest output and slots survive. Ordinary output evaluation prunes those unread dependencies; independent selected roots still run and explicit input inspection resolves the inputs. Cache retains its control reads before a missing/disabled-input return, while the outer auto-cache retains the latest output for that missed frame. Automatic group enable/disable effects still require integration.

The same Array early returns skip authored control-track sampling in the initial timeline pass and dynamic PCX refresh. Explicit input inspection still samples those tracks. Independent consumers can still require inherited or inline-owner tracks; a skipped Array does not suppress their getters.

`ApplySourceFrameCacheGroupReplay` owns branch-selected Enable/Disable transactions. Enable respects Serialize/loading/appending gates, wakes retained member lists and force-clears all owner processor rows while keeping the latest output. A later Cache outer capture can retain that output in the current frame without restoring the cleared history. Both actions admit prior/destination/replacement journals and validation workspace before publication. This API shares the button mutation path; automatic evaluator dispatch still needs to apply selected transactions and refresh activity/dependencies before enabled nonempty groups can execute.

Auto-Cache hits bypass all connected input getters and producer-track sampling before dispatch, matching the source `doUpdateLite` recovery branch. This includes paused and played hits from retained row-zero snapshots, exact-source decoded receipts and cold cooked constructor packets. The scheduler indexes borrowed rows once under the live allocation budget, preserves node-wide constructor suppression and limits a newly loaded Cache to TOTAL_FRAMES slots. Frame lookup accepts surfaces and arrays, while `noone` and numeric sentinels remain misses. Cache Array keeps its manual capture policy. Independent selected roots still execute, and explicit input inspection still resolves the authored inputs. A miss reads Animated before its playback/producer return. Cold native hit inspection validates the complete identity-bound packet without decoding pixels or constructing failure diagnostics. Sparse frame lookup accepts root surfaces and arrays only after all trailing bytes and nested payload bounds pass. Existing runtime rows and selected decoded load rows take precedence even when they contain no hit; node-wide clear suppression prevents cooked fallback in unseen processor rows. Decode ownership and byte admission still belong to the kernel. This hit cut does not enable automatic nonempty group transitions or defer all pending-member timeline reads.

Late PCX dependencies extend timeline samples within the same immutable document/request observation. Already sampled nodes keep their values; newly needed animated nodes join in sorted order. Prior samples, new samples and replacement tables coexist under the live byte limit before ownership moves. A refused extension keeps prior samples and their charge.

Frozen nodes and cache hits retain their getter cuts; authored-value inspection keeps its explicit sampling path. Admission masks use the live byte budget, and repeated mask/track scans share the scheduler's work limit. This ordering prepares activity-changing transactions; those transactions remain guarded.
