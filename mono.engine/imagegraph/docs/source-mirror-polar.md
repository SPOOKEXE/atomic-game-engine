# Source Polar Mirror CPU profile

`pc.mirror_polar` executes the pinned `Node_Mirror_Polar` constructor and `sh_mirror_polar` fragment arithmetic from revision `b69eca232217360cf1502ef0223523d818606652`. Exact source file SHA256 values accompany the implementation in `source-mirror-polar-sha256.json`. This is a bounded deterministic CPU profile, not a verified GPU output comparison.

The native producer preserves all three output-dimension modes, raw relative dimensions, half-even storage rounding and the fresh project's Constant-dimension default. Position and Center use their distinct Pixel/Reference controls. Reference units use raw `getDimension(0)` before processor row selection and storage rounding. Linked numeric values still receive units; linked surfaces return physical dimensions directly. Scalar numeric getters broadcast to both vector components. The normal processor scheduler supplies Loop, Hold, Expand and Expand inverse rows and inherited instance/animated controls.

The polar kernel preserves the source row-vector rotation, degree angles, floor-based negative modulo, reflective sector doubling/folding, angular scale, linear or exponential radial scale, trim after radial scaling, and final coordinate `fract`. The two following floor/parity branches in the source cannot change a finite fractional coordinate and are omitted. Alpha comes from the sampled source without brightness or alpha premultiplication. Spokes map RGB arithmetic mean ignores map alpha, reads the unfiltered/clamped map at the original output UV, and interpolates the source range. Spokes curves use the shader's radial normalized distance, strict step comparison, Bezier/Newton evaluation and range header. The defined GLSL profile accepts one to nine anchors with nonzero header scale; the separate HLSL 512-float uniform profile is not advertised.

Interpolation and depth follow the source attributes. Pixel, Bilinear, Bicubic and the source's nine paired Lanczos taps use the shared sampler mathematics. Local finite-coordinate/divisor guards prevent undefined sampling casts and return a diagnostic without publishing a replacement image. CleanEdge uses the source edge-slicing helper locally, including inherited interpolation. Oversample cannot affect finite final polar UVs after `fract`. Native `atan2(0,0)` gives zero; the source GPU center angle and floating precision remain comparison gates.

Safe drawing replaces the polar shader for R8/R16/R32 source surfaces. That branch stretches the original red channel with the source base texture filter, replicates red into RGB, and supplies alpha one. It does not evaluate spoke division, curves, polar transforms or CleanEdge. Inactive processors clone the source dimensions, depth and bytes, ignoring the active output-dimension controls.

Before processor rows run, the native evaluator detects Path2D values on the five vector controls and samples each through `PathRuntime::PointRatio` with the consumer's local raw animator. It reads the ratio from `Vector2.X` or the first scalar or integer in a flat array value. When no raw local animator is available, it uses the constructor default, including raw project width for Constant Dimension. Each sampled point is installed as a Vec2 through evaluator-reserved value-view storage, and the original views and sample flags are restored afterward. Sampled Position and Center bypass Pixel/Reference conversion because their path points are already resolved coordinates. Missing or invalid ratios return an unsupported diagnostic. No filesystem, host RNG or persistent replay state is used.

## Admission and publication

The allocation-free first-row preflight scans original owned or borrowed controls, image arrays and retained Surface/Atlas values before selected row views hide expensive later rows. It bounds independent width/height extrema across the actual output-dimension modes and includes source-sized clones whenever an inactive row is possible. It admits `ProcessorCount` times the worst rounded pixel count under 64 million conservative work units. Active pixels cost128 units for maps, polar transcendental work, paired sampler taps and writing; a possible curve raises that bound to704 for the maximum GLSL anchors/Newton work. Entirely inactive batches use one unit per cloned pixel. These are native policy bounds, not performance measurements.

The producer allocates no heap workspace. `NodeContext::NewImage` admits the exact selected-format layout, output collection and durable port storage. Existing evaluator processor folding and transactional publication account the aggregate and preserve the prior selected image/array on failure. Finite controls that produce undefined radial distance, zero/nonfinite spoke sectors, angular modulo or sampler coordinates return `InvalidValue`; dimensions and whole-batch limits return `LimitExceeded`.

The authored suite covers independently derived coordinate pixels, scalar and linked getters, mapped ranges/alpha, curves, both radial modes, signed scales, trim, sampling/depth, red safe draw, inactive cloning, raw Reference dimensions, original row topology, persisted selected consumers, arrays, inherited animation and atomic byte/work refusal. Joined release66 CPU checks pass all 29 Mirror cases. The successful topology fixture was corrected to supply its normal allocation budget; its pixel oracle is unchanged. Sanitizers, measured profiling and source GPU comparison remain open.

CleanEdge (interpolation 6) uses the pinned sampler_ext 21-neighbor edge slices in Up, Back, Corner order. The Mirror Polar and Refract sampler regions are byte-identical (14,397 characters, SHA-256 `4777ee33bf8a9af926792394a8a214022270b0704735be8decbb2f3dc25c3917`), so this node reuses the bounded private source helper. Folded UV coordinates are already wrapped by the polar shader before sampling. CleanEdge adds 4,096 conservative work units per active pixel to the whole processor batch, including inherited interpolation and any original array row selecting it. Single-red safe drawing retains its source stretched-sampling path. These scoped checks await joined verification.
