# Bubble Noise CPU contract

`pc.noise_bubble` executes the pinned `Node_Noise_Bubble` and `sh_noise_bubble` formulas at source revision `b69eca232217360cf1502ef0223523d818606652`. The output is `surface_out`. The native profile uses double arithmetic, pixel-center coordinates, nearest surface sampling and the existing typed surface pipeline. Shader float precision, sine hashes, filtering and actual device pixel parity need a captured renderer oracle. No device parity is claimed.

The authored Seed is mandatory. The constructor's random initial seed is not fabricated; provided seeds use the literal sine/fract hash and floor modulo 100000. Four hashes per bubble set its X, Y, radius and opacity. Density defaults to `.5`. The source loop count is the signed shader-int truncation of Density times raw canvas width; negative and subinteger counts execute no iterations. Raw Y aspect is height divided by width. Allocated dimensions round half to even, while raw canvas dimensions still determine aspect, count and half-texel line support.

Scale defaults to `{.5,.8}` and Opacity to `{0,1}`. Their endpoints interpolate by different hash observations and may reverse. Line uses the larger of Thickness and half the smaller reciprocal dimension; Fill uses radius plus/minus Thickness. Mode is Line 0 or Fill 1, and Blend Mode is Max 0 or Add 1. The resulting intensity passes through Level In and Level Out, both default `{0,1}`, before storage. Inverted levels and unclamped extrapolation are preserved. No mapped numerical control or Active control exists in this constructor.

Fill with nonpositive Thickness has non-increasing `smoothstep` edges. This branch is diagnosed only when its loop actually runs. An empty loop remains defined, including Fill at zero Thickness. Edge collapse in native arithmetic, a zero raw divisor, zero Level In span, unrepresentable shader-int count and nonfinite hash/coordinate/interpolation results are diagnosed. The CPU profile does not substitute a step function for undefined shader behavior. The GLSL definition requires increasing edges for defined smoothstep results: [Khronos GLSL specification, section 8.3](https://registry.khronos.org/OpenGL/specs/gl/GLSLangSpec.4.60.html).

The inherited Dimension supports Pixel, Project and Mask units. Linked Dimension surface arrays project constituent sizes before processor selection, with equal-size collapse. Scalar surface Slider getters for Density, Thickness and UV Mix produce dimension components before scalar row selection. The four SliRange inputs project a scalar surface's dimensions; a whole surface array takes the source nonsurface `{1,1}` fallback. Numeric scalar range links duplicate the component. Short numeric tuples pad zeros, longer tuples clip to two components. Seed uses its base source NodeValue contract; surface-handle casting is not invented.

UV Map reads red X and inverted green Y, interpolates by UV Mix, and applies map alpha even at zero Mix. The source mask uses an RGBA8 intermediate, mean RGB times alpha, and final typed storage. Mask Alpha Only is source-inert here. Inherited project formats and the seven explicit depths remain typed and bounded.

Whole-batch work is admitted before output allocation. Original Density leaves and the largest absolute raw canvas width across source units and surface rows conservatively bound every loop, including signed and mixed-unit inputs. The quote is 512 weighted reads/arithmetic/math-call units per pixel plus 128 per admitted bubble. The 64M bound includes four hashes, distance, smoothstep, blend, UV/mask reads and typed writes. As with other complex generators, 16 bytes per pixel and row metadata are quoted for every output row before a later row selects its format. Inputs stay charged and output replacement is atomic on failure. This conservative absolute-count quote can reject a large negative no-loop input earlier than its empty per-pixel loop would require; this is an explicit native admission bound.
