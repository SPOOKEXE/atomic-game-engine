# Surface Project 3D

`pc.surface_project_3_d` follows the constructor and GLSL shader from Pixel Composer commit `b69eca232217360cf1502ef0223523d818606652`. This is a bounded CPU execution profile. Device sampling, raster precision, ambient draw tint, shader compiler rounding and licensed desktop comparisons remain separate verification gates.

The wrapper first tests original Top/Front/Right presence when choosing fallback surfaces. It clears an RGBA8 atlas of three by three cells, draws Front/Right/Top into its first row, and Back/Left/Bottom into its second row at their original pixel sizes. Smaller faces leave transparent padding. Back faces larger than a cell spill into later cells in source draw order, clipped only at the complete atlas boundary. The shader calls these physical slots Top/Front/Side. The back enable flags deliberately follow the wrapper's crossed assignments. Missing all primary faces leaves ambient source output surfaces; the pure evaluator refuses that branch rather than inventing a retained frame.

Camera projection, view angle, position, FOV, Distance and Scale retain the source float inverse rotation and voxel traversal. Output dimensions determine voxel size. Near-zero direction components become positive `0.001` without normalization. Alpha determines occupancy, including the optional opposite-side thresholds. Noise uses the literal float hash and authored Noise Seed, independently of GameMaker's PRNG. An unresolved seed used by enabled Noise is refused. Shader traversal stops at its literal bound or first occupied voxel.

Voxel Color supports the exact face, all-face average and except-axis branches. The GLSL palette upload profile admits 1 through 256 colours. Face Blending cycles source face indices, including signed back-face indices, rather than physical texture slots. Palette alpha has no effect. The source Palette getter wraps scalar colours into one-entry palettes. Native Colour and integral low-32-bit packed colours use the existing shared conversion; fractional/out-of-range packed conversion remains an explicit boundary. Outputs are Surface Out, Depth Pass and Normal Pass. Depth divides geometric ray distance by Scale then applies Depth Range; normal is the voxel step mask, including its source zero mask for a first-iteration hit. Undefined camera, selector and depth arithmetic has an explicit diagnostic.

Atlas copies expand single-channel source textures to grayscale with alpha one using the pinned channel shaders. Source atlas blending adds source RGB to destination RGB weighted by inverse source alpha, with additive alpha. Transparent later faces preserve earlier RGB. The CPU profile uses normalized RGBA8 encoding after each draw; device blend precision remains unobserved. Device filtering applies to the complete packed atlas, including cell-boundary interpolation. Bicubic and Lanczos choices enable linear device filtering because this projector calls plain `texture2D`. All seven owned output formats are supported. The native profile uses white ambient tint; device-observed tint is not claimed.

Whole original processor rows are scanned before first output allocation to bound dimensions, traversal distance, source-face validation, packed atlas work and three attachments. Each row owns a temporary atlas and publishes all three attachments together. Errors preserve the caller's previous result. Numeric Surface getter projection preserves scalar Surface dimensions and whole Surface-array nonsurface dimensions before processor selection. Float and Slider getters create two scalar rows; Vec3 and Range getters retain one tuple. Noise Seed uses plain NodeValue and receives no invented Float getter projection. General tuple admission is scoped to Dimension, View Angle, Position, Depth Range and Face Blending; source Path objects are not fabricated as numeric uniforms.

Row-zero admission scans original dimension units before creating the atlas or attachments. Any Project choice scales the original unlinked dimension bound by project dimensions. Linked dimensions preserve the source Pixel override. A later Mask choice refuses before allocation because this source projector exposes no configured mask dimension input.

The pinned Dimension unit is attributes.use_project_dimension, edited by a scalar side button. A native link supplying an array to the synthetic dimension_unit port remains an explicit scalar-reader refusal. Original-unit scanning is defensive native admission, not a source claim that this attribute batches across processor rows.
