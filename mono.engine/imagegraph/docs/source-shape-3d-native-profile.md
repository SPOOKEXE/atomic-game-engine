# Draw Shape 3D native execution profile

The `pc.shape_3_d` CPU executor uses `NativeTopOrigin`: image rows increase downward, screen coordinates are `((clip.x+1)*width/2,(1-clip.y)*height/2)`, and hardware test depth is stored orthographic clip Z in [0,1]. Depth output always uses raw clip Z and the authored View Range. `HTML5FramebufferRows` is an independently selectable preparation profile, not an authored node control.

Pinned Pixel Composer source b69eca232217360cf1502ef0223523d818606652 supplies the nine geometry constructors, Cube VB order [1,3,5,0,2,4], world push sequence, fixed look-at camera, orthographic projection, shader surface/depth/rim formulas and texture/palette wrapping. The matrix rotation signs and multiplication order were checked against official GameMaker HTML5 runtime commit 60e51be51ce7f3d52025ef18106cf172b8e22a00. Camera algebra gives view=(-world.x,-world.z,1-world.y), clip=(-2*world.x,-2*world.z,(1-world.y)/2,1).

This native profile deliberately specifies finite zero normals as zero, including Octahedron's source-authored zero normals. It uses double arithmetic, affine orthographic varyings, top-left triangle coverage, counterclockwise screen culling and less-or-equal depth writes. These are deterministic engine conventions. Pinned Windows runner matrix precision, surface row conversion, driver coverage and normalize(0) behavior have not been verified. No licensed reference parity is claimed.

Array Texture disabled processes each surface in an outer texture array as a separate processor row. Enabled consumes a flat list per row and wraps texture selection by source submesh index. Nested image lists are processor rows, including empty inner lists, which use white texture. Malformed mixed/deeper lists refuse before execution. Palette arrays remain per-submesh values. Displacement controls are source-read but unused by the pinned shader.

Geometry and projection each quote 64 work units per vertex across ProcessorCount before allocating/filling triangles. Executor batch admission quotes their combined cost plus full-target bounds for every triangle, sampler cost, attachment writes, palette and every referenced image sample validation. The shared ceiling is 64 million work units. Raster also checks its tighter projected bounding-box work before allocating attachments. All three images are computed before graph publication; output failure clears partial publication, and evaluator results retain their previous value on refusal.

Focused acceptance suites are SourceShape3D, SourceShape3DGeometry, SourceShape3DProjection, SourceShape3DRaster and SourceShape3DExecutor. Coordinate expectations are derived independently, not captured from a GameMaker run. The nonuniform-normal case distinguishes source forward-normal multiplication from inverse transpose.
