# Procedural planets: retained contracts

## Status

[`FULL-PLANET-DEMO.md`](FULL-PLANET-DEMO.md) owns the product slice,
[`terrain-system.md`](terrain-system.md) owns terrain progression, and
[`procedural-generation.md`](procedural-generation.md) owns generation requests,
identity, scheduling, and publication. This file retains planet-specific
contracts those plans do not spell out. It is not a second planet roadmap.

## Deterministic cube-sphere contract

- A planet is a radial heightfield over six cube faces. It cannot represent
  caves, overhangs, or detached islands. Those require the later SDF terrain
  domain.
- Face identity is topological and serialized by name: `+X`, `-X`, `+Y`, `-Y`,
  `+Z`, `-Z`. It never derives from declaration order or a process-local id.
- Requests use integer face coordinates and dyadic ranges. Parent samples that
  coincide with child samples take the same arithmetic path, so a level change
  cannot introduce a different edge value.
- The selected spherified-cube mapping is evaluated in the documented order:

```text
s.x = x * sqrt(1 - y*y/2 - z*z/2 + y*y*z*z/3)
s.y = y * sqrt(1 - z*z/2 - x*x/2 + z*z*x*x/3)
s.z = z * sqrt(1 - x*x/2 - y*y/2 + x*x*y*y/3)
```

  Clamp only a tiny negative radicand caused by rounding within a validated
  cube domain. A materially negative value rejects the request.
- Direction-space sampling is planet-local. Radius, rotation, and translation
  do not alter a graph's field identity. Normalize finite nonzero directions at
  the request boundary once.
- Every cube edge has a tested neighbor face, neighbor edge, and parameter
  reversal. Normals use the same direction-space basis and sample rule across
  a seam. Skirts may hide a visual crack but cannot repair a normal or
  collision mismatch.

## Publication and authority

- Replicate and save the recipe, generator version, and request identity, never
  generated mesh bytes. Collision and gameplay artifacts publish only at the
  world mutation barrier.
- A request identity includes body name, recipe digest, face, dyadic patch
  coordinate, level, output, and epoch. A completed result commits only while
  that exact identity is still desired.
- A patch reports a fixed mesh resolution, deterministic bounds, generation
  revision, and explicit residency state. Neighbor levels differ by at most
  one. Resource admission accounts for samples, layers, octaves, target bytes,
  and outstanding requests before allocating.
- Floating origin changes render-space representation only. Body-space graph
  inputs, orbit state, saved bookmarks, and canonical recipe bytes remain in
  Float64 metres.

## Required proof

- Fixed recipe output is identical for body, face, patch, and level across
  worker counts.
- All twelve face edges and eight corners preserve positions, normals, and
  index ownership.
- Parent and child boundary samples match exactly, stale work cannot publish,
  and cancellation releases bounded resources.
- A release scene records patch count, generated bytes, queue age, retained
  bytes, visible triangles, and seam failures before any scale claim.
