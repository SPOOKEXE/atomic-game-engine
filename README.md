
# Atomic Game Engine

A 3D game engine for Roblox Developers looking for more advanced capabilities.

## Features

- **C++ Engine:** C++ for lightning fast performance and availability.
- **Embedded Scripting:** Luau and TypeScript/JavaScript for high-level scripting and programming.
- **Node Systems:** Integrated node systems for graph-based operational work. Works like Blueprints.
- **C++ Bindings:** C++ binded libraries for high performance - signals, events, quadtrees, octrees, ECS, and even more!
- **ECS-driven:** Component-based engine systems for the highest performance.
- **Multiplatform:** Windows, Linux, MacOS, Android, IOS and VR.
- **Sandboxed:** You download the engine, you can load any game file and play yourself or with others.
- **Multi-Deployment:** Play singleplayer, LAN, Peer2Peer and online. The architecture supports them all.
- **Permissive License:** You can do a lot of things with this engine, with attribution of course.
